## Mise en ligne GitHub Pages

1. Décompresser le ZIP.
2. Ouvrir le dépôt `lloyddigitalstudio.github.io`.
3. Choisir **Add file → Upload files**.
4. Téléverser tous les fichiers à la racine.
5. Valider avec **Commit changes**.
